# System Flowchart

## Overview

The system follows a step-by-step process to generate flood predictions.

1. User opens the web application.
2. User enters flood-related parameters.
3. The application validates the input.
4. Input data is preprocessed.
5. The trained Machine Learning model is loaded.
6. The prediction engine generates the flood prediction.
7. The result is displayed to the user.
